# 🌌 Neon Typing Arcade 🦕

Welcome to **Neon Typing Arcade** — a collection of kid-friendly, web-based typing games built with vanilla HTML, CSS, JavaScript, Web Audio chiptune music, and Web Speech pronunciation!

---

## 🎮 The Games

### 1. 🏠 Arcade Hub (`index.html`)
Landing page linking both games and displaying your saved best scores from `localStorage`.

### 2. 🌌 Neon Plane Typing (`plane-game.html`)
An arcade space-shooter typing game! Lock onto incoming alien ships by typing their first letter and complete words to blast them.
* **3 Stages & Distinct Bosses**: Progress through *Neon Nebula* (Nebula Mothership), *Cyber Asteroid Belt* (Aegis Core), and *Dark Void* (Void Dreadnought).
* **Vocabulary Sectors**: Quantum Cosmos (Sci-Fi), LAUSD Grade 3 ELA, LAUSD Grade 4 ELA, plus a **Custom Spelling List** sector and **Practice Missed Words** drill mode.
* **Power-Ups & Controls**: Shield (`🛡️`), EMP Slow-Mo (`❄️`), Heart (`❤️`), `Easy`/`Normal`/`Hard` presets, `Tab`/`Backspace` target unlock, and `ESC` pause.
* **Audio**: Procedural Web Audio chiptune soundtrack per stage/boss, synth SFX, and Web Speech word pronunciation.

### 3. 🦕 Dinosaur Adventure Typing (`dino-game.html`)
Type full sentences to guide Rex across 5 prehistoric biomes!
* **Visuals**: Animated SVG dinosaur, drifting clouds, biome transitions, goal treats, and confetti bursts.
* **Audio & Learning**: 50-sentence pool across 5 levels, procedural chiptune music, fanfares, and Web Speech sentence read-aloud.
* **Stats**: Net WPM, Accuracy %, and saved Best WPM/Accuracy.

---

## 🚀 How to Play

No installation or build tools required!
1. Clone this repository or download the ZIP.
2. Open **`index.html`** in any modern web browser (or launch **`plane-game.html`** / **`dino-game.html`** directly).
